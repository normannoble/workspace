How It Works

Three core systems working together to create an autonomous trash-catching experience

AI Object Detection

Custom-trained model recognizes trash in your hand using a webcam feed. Built with 1,000+ manually labeled images per object class.

Arduino-Powered Movement

Dual motorized wheels with L298N driver enable precise navigation. Caster wheels provide smooth omnidirectional rolling.

Python Integration

Real-time communication between AI detection and motor control. Features 50ms command memory for smooth tracking.
