Technical Details

Hardware specifications, software architecture, and implementation details behind Lazy Bin

Hardware Components

Arduino

Microcontroller

Central brain that receives commands via serial communication and controls the motor driver outputs.

L298N Motor Driver

Motor Controller

Dual H-bridge driver that controls the speed and direction of both DC motors using PWM signals.

DC Motors (x2)

Motorized Wheels

Two independently controlled motors for differential drive steering - enabling forward, backward, and turning motions.

Caster Wheels (x2)

Passive Support

Omnidirectional caster wheels provide balance and allow smooth movement in any direction.

9V Battery

Power Supply

Portable power source with switch for easy on/off control. Powers both the Arduino and motors.

False Bottom

Enclosure

Custom-built compartment that conceals and protects all electronics while maintaining the bin's functionality.

Custom AI Model

After evaluating thousands of existing trash detection models on Hugging Face, none met the accuracy requirements for this specific use case. The solution was to train a custom model from scratch.

  • Training Data: ~1,000 manually labeled images per object class
  • Labeling Time: Approximately 7 hours per object class
  • Model Base: Built on YOLOv8 architecture for real-time detection
  • Detection Target: Trash items held in human hands
  • Output: Bounding box coordinates used to calculate movement direction
  • Processing: Runs on computer, sends commands to Arduino via serial

Control Commands

The bin responds to simple character commands sent via serial communication:

// Movement Commands (sent from Python to Arduino)
'W' - Move forward
'S' - Move backward
'A' - Turn left
'D' - Turn right
'X' - Stop all motors

// The Python script converts AI detection coordinates
// into these simple directional commands
if trash_x < center_x:
    send_command('A')  # Turn left toward trash
elif trash_x > center_x:
    send_command('D')  # Turn right toward trash
else:
    send_command('W')  # Move forward

Key Features

  • Autonomous Navigation: Bin detects trash in your hand and drives toward you automatically
  • Return to Home: After trash is deposited, the bin remembers its starting position and returns to its resting spot
  • 50ms Command Memory: Smooths out movement when AI tracking momentarily loses the target
  • Motor Balancing: Software compensation for motor strength differences ensures straight-line driving
  • Continuous Input: Python script handles held keys for smooth manual control via keyboard or joystick
  • Clean Design: False bottom conceals all electronics while maintaining normal bin functionality
